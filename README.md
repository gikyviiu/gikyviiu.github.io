## Используемые технологии

- **JavaScript** – программирование на стороне клиента
- **HTML5** – структура веб-страниц
- **CSS3** – стилизация и анимации
- **Bootstrap 5** – CSS-фреймворк для адаптивной верстки
- **DOM API** – работа с документом и событиями
- **Figma** – дизайн-макеты для верстки
